# 黑龙 · 安全自查与应急响应工具

一个**纯静态、零后端**的安全自查工具：按清单核对账号、备份、主机、终端的配置现状，
得到风险分与按优先级排序的加固清单，并内置四类安全事件的应急响应流程。
**所有计算在本机完成，输入不上传、不联网。**

> ⚠️ **合法使用边界**：本工具仅用于你**自己拥有**或**已获得书面授权**的系统、账号与设备。
> 未经授权对他人系统进行测试、扫描、探测，可能违反《网络安全法》及《刑法》第 285 条、第 286 条，
> 请务必在合法授权范围内使用。**本工具不提供任何扫描、探测、破解、绕过或攻击功能。**

## 功能模块（9 个模块 / 62 条清单项）

| 模块 | 内容 |
|---|---|
| **口令强度与熵值** | 字符集、长度、熵值（bit）、弱模式识别（连续字符、键盘行走、年份、完整日期、重复片段、手机号、常见口令）→ 分级与改进建议。**输入后立即清空，不显示、不存储、不进报告** |
| **哈希/编码格式识别** | 按长度与字符集推测类型（MD5/NTLM、SHA 系列、bcrypt/argon2/scrypt、JWT、PEM、Base64/32、UUID/MAC 等）。**仅识别，无解密、无碰撞、无查询** |
| **钓鱼与诈骗自评** | 15 项特征（域名伪装、紧迫话术、索要验证码、要求转账、远程控制、冒充官方等），高危项命中即判高风险并给处置动作 |
| **账号安全自查** | 两步验证、口令复用、恢复邮箱/手机、登录设备、OAuth 授权、免密支付、邮箱转发规则、补卡攻击 |
| **备份与数据安全** | 3-2-1 原则、加密、离线异地、自动周期、恢复演练、应急访问 |
| **主机/服务器暴露面** | 端口最小开放、管理入口不暴露公网、禁 root 直登、默认口令、补丁与版本清单、日志外发与告警、最小权限、数据库隔离、变更回滚。**纯核对表，含判断标准，零扫描/探测指引** |
| **手机与个人设备** | 系统更新、锁屏与加密、应用来源、权限收敛、越狱/root 风险、公共 WiFi、查找设备、旧设备清除 |
| **应急响应** | 4 个场景（账号被盗 / 勒索软件 / 服务器被入侵 / 数据泄露）：分步处置、需保留的证据、应联系谁（96110、110、公安网安、云厂商、法务）、**禁止事项**（严禁支付赎金、严禁删除日志、禁止反向攻击） |
| **报告输出** | 总体风险分与等级 → 各模块得分 → 按高/中/低优先级的加固清单 → 未落实项明细 → 法律边界 → 方法说明。支持导出文本与打印/存 PDF |

## 使用

打开页面 → 勾选授权确认 → 逐项核对 → 生成报告。草稿自动保存在本机浏览器；
**口令输入框与格式识别框的内容不会写入任何存储**。刷新后可继续。

## 隐私

无后端、无埋点、无第三方脚本、无任何网络请求。所有数据仅存在于你的设备。
